# Security Policy

## Project

video-analyzer maintainers welcome responsible reports about security issues.

## Supported Versions

Only the latest release \(\>=0.1.0\) receives active security updates and vulnerability patches.

## Reporting a Vulnerability

Please do not disclose vulnerabilities through public discussion or pull requests.

Send a report to the monitored security contact: security@example.com

Include:
- A description of the vulnerability and its potential impact.
- Clear reproduction steps, a minimal proof of concept, or command sequence.
- Affected versions, platforms, and configuration details.

## Response & Disclosure Process

Maintainers will acknowledge receipt within 48 hours, validate the report within 7 business days, and coordinate remediation and public disclosure via GitHub Security Advisories.
