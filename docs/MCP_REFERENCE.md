# Vidscope MCP Tool Reference

> **Notice**: This document is auto-generated by `scripts/generate_mcp_docs.py` (or `vidscope docs`).

Vidscope exposes a Model Context Protocol (MCP) server over standard I/O (`stdio`).
Clients and agent harnesses can connect via `vidscope-mcp` or `vidscope mcp`.

## Interactive Inspection

To inspect tools, schemas, and live executions interactively using the official MCP Inspector GUI:


### `analyze_video`

Analyze a video and extract a token-efficient visual & speech timeline.

Runs synchronously for up to sync_timeout_seconds (~5s). If the analysis finishes
within this window, returns the complete timeline immediately. For longer videos,
seamlessly transitions to background processing and returns a job_id with estimated
time to completion.

#### Input Parameters

| Parameter | Type | Required / Default | Constraints | Description |
|:---|:---|:---|:---|:---|
| `source` | `string` | **Required** | - | URL or local path of the video to analyze |
| `start_seconds` | `number` | Optional (default: `0.0`) | >= 0.0 | Start offset in seconds (must be >= 0) |
| `end_seconds` | `number \| null` | Optional (default: `None`) | - | Optional end offset in seconds |
| `chunk_duration_seconds` | `number` | Optional (default: `180.0`) | > 0.0, <= 180.0 | Duration of each analysis window in seconds (0 < duration <= 180.0) |
| `sync_timeout_seconds` | `number` | Optional (default: `5.0`) | >= 0.0 | Maximum seconds to wait synchronously before transitioning to background job |

#### Realistic Request Example

```json
{

  "chunk_duration_seconds": 180.0,
  "sync_timeout_seconds": 5.0
}
```

### `get_transcript`

Retrieve timestamped speech transcript segments and joined dialogue text for a video time range.

Requires a completed analysis job. Bounded to max_duration_seconds (up to 600s/10min)
to protect agent context windows.

Filtering is overlap-based: segments that overlap [start_seconds, end_seconds] are
returned (a segment may start slightly before start_seconds if it ends after start_seconds).
Returned segments are guaranteed to be sorted monotonically by (start_seconds, end_seconds).

**Hints**: `readOnly: true`, `idempotent: true`

#### Input Parameters

| Parameter | Type | Required / Default | Constraints | Description |
|:---|:---|:---|:---|:---|
| `job_id` | `string` | **Required** | - | Analysis job ID from analyze_video to read transcript from |
| `start_seconds` | `number` | Optional (default: `0.0`) | >= 0.0 | Start offset in seconds (default: 0.0) |
| `end_seconds` | `number \| null` | Optional (default: `None`) | >= 0.0 | End offset in seconds. If omitted, defaults to start_seconds + max_duration_seconds |
| `max_duration_seconds` | `number` | Optional (default: `300.0`) | > 0.0, <= 600.0 | Maximum allowed transcript window duration in seconds (default: 300.0, max: 600.0) |

#### Realistic Request Example

```json
{
  "job_id": "job_e7b29a14-8f43-4c9b-98f2-1d573be04f21",
  "start_seconds": 15.0,
  "end_seconds": 45.0,
  "max_duration_seconds": 300.0
}
```

### `search_video`

Search the transcript of an analyzed video using job_id.

Requires a completed analysis job to prevent false negatives.
Supports substring and regex matching.

**Hints**: `readOnly: true`, `idempotent: true`

#### Input Parameters

| Parameter | Type | Required / Default | Constraints | Description |
|:---|:---|:---|:---|:---|
| `job_id` | `string` | **Required** | - | Analysis job ID from analyze_video to search transcript |
| `query` | `string` | **Required** | - | Text or regex pattern to search for in transcript |
| `is_regex` | `boolean` | Optional (default: `False`) | - | Whether to treat query as a regular expression |
| `case_sensitive` | `boolean` | Optional (default: `False`) | - | Whether search should match case sensitivity |
| `max_matches` | `integer` | Optional (default: `20`) | > 0 | Maximum number of matches to return |

#### Realistic Request Example

```json
  "query": "strangers to love",

  "case_sensitive": false,
  "max_matches": 10
}
```

#### Realistic Response Example

### `view_frame`

View a video frame as a native MCP Image content block with OCR metadata.

Can retrieve an extracted keyframe via frame_id, or extract a frame on demand
given source and timestamp_seconds.

**Hints**: `readOnly: true`, `idempotent: true`

#### Input Parameters

| Parameter | Type | Required / Default | Constraints | Description |
|:---|:---|:---|:---|:---|
| `frame_id` | `string \| null` | Optional (default: `None`) | - | Keyframe identifier from analyze_video timeline (mutually exclusive with source/timestamp) |
| `source` | `string \| null` | Optional (default: `None`) | - | Video URL or path to extract a frame on demand (requires timestamp_seconds, mutually exclusive with frame_id) |
| `timestamp_seconds` | `number \| null` | Optional (default: `None`) | >= 0.0 | Timestamp in seconds to extract frame on demand (requires source, mutually exclusive with frame_id) |
| `max_width` | `integer` | Optional (default: `1280`) | > 0 | Maximum frame image width in pixels |

**Mutual Exclusivity Constraints (`oneOf`)**:
- Requires: `frame_id`
- Requires: `source`, `timestamp_seconds`

#### Realistic Request Example

```json
{
  "frame_id": "frame_0000_003600",
  "max_width": 1280
}
```

#### Realistic Response Example

```json
{
  "content": [
    {
      "type": "text",
      "text": "{\n  \"frame_id\": \"frame_0000_003600\",\n  \"timestamp_seconds\": 36.0,\n  \"formatted_time\": \"00:00:36\",\n  \"ocr_text\": \"Rick Astley - Whenever You Need Somebody\"\n}"
    },
    {
      "type": "image",
      "mimeType": "image/jpeg",
      "data": "<base64_encoded_jpeg_bytes>"
    }
  ]
}
```

## MCP Resources

Vidscope provides static and dynamic resources for inspecting runs, DAG plans, and server telemetry.

| Resource URI / Template | Name | Description |
|:---|:---|:---|
| `vidscope://info` | `server_info` | Server capabilities, active version, and available resource URI templates. |
| `vidscope://runs/{run_id}/artifacts/{artifact_id}{?page,offset,limit}` | `read_artifact` | Retrieve raw artifact content or paginated text by run ID and artifact ID. |
| `vidscope://runs/{run_id}/manifest` | `read_manifest` | Retrieve execution manifest and output file metadata for an analysis run. |
| `vidscope://runs/{run_id}/plan` | `read_plan` | Retrieve deterministic DAG execution plan JSON for an analysis run. |
